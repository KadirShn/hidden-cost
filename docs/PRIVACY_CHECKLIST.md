# Privacy Checklist

- [ ] Cost values are not sent to Analytics.
- [ ] Project titles and notes are not sent to Analytics.
- [ ] Logs do not contain user-entered cost data.
- [ ] Cloud backup is optional.
- [ ] Analytics consent can be changed.
- [ ] Advertising privacy options can be reopened.
- [ ] Local and cloud data deletion exist.
- [ ] Firestore ownership rules are tested.
- [ ] Privacy policy is reviewed before release.
