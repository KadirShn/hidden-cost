# Calculation Engine

## Core equation

```text
Total Cost of Ownership =
  Purchase Price
  + Initial Costs
  + Recurring Costs
  + Usage Costs
  + Financing Costs
  - Net Residual Value
```

The financed principal must not be added a second time because the purchase price is already included. Only financing interest and fees are additional ownership costs.

Money arithmetic will use minor units and decimal arithmetic rather than native floating-point accumulation.
