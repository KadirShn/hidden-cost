# Changelog

## [Unreleased]

### Changed
- The calculation wizard now asks for every template cost line (insurance, tax, parking, marina,
  subscription fee, …) with an editable payment frequency, and supports custom lines.
- Fuel/energy inputs match the category: L/100 km for vehicles, L/hour for boats, and device
  wattage for electronics (electronics template v2 measures usage in hours). Subscriptions no
  longer ask for fuel.
- Usage units are translated in the wizard and PDF report.
- Prepared the ad-free 2.0.0 release.
- Removed native, interstitial, and rewarded advertising integrations.
- Made PDF and comparison exports directly available without an advertising gate.

### Added
- Initial product specification
- Architecture proposal
- Privacy and release checklists
- Architecture Decision Records
